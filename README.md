# Android Socket Programming (Assignment 1)
## Overview
This project implements a **TCP and UDP** client-server communication system between an Android application and a Python-based CLI application.

## Features
- Supports **both TCP and UDP** communication.
- Implements **multi-threaded** servers in both Kotlin and Python.
- Allows users to send and receive messages in real time.
- Logs network activity for analysis.
